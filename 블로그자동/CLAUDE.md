## 아키텍처 — 3단 파이프라인

**① 생성기**(`gen_*.py`) → 원고 + 에셋을 `~/홈판자료/블로그오토/gen_YYYYMMDD/`에 저장
- 파일 규약: `{편번호}_{키워드}_복붙용.txt`, `_썸네일.png`, `_표.html`, `_제목후보.txt`, `_연예캡처N.png`, `_ai.flag`
- 본문은 **마커**를 품는다: `[사진N - 설명 / 출처: …]`, `[표]`, `[커넥트 - 제품]`

**② 조립**(`pipeline.process_post`) → 마커를 네이버 블록으로 변환
- `posts.category()`가 파일명·`_ai.flag`로 `ai|shopping|celeb|insight` 판정 → 종류별 분기
- `parse_post.parse_rewritten(text, asset_map)` → `(제목, 블록리스트)`. 블록: `text·photo·image·quote·quote2·table_paste·connect·hashtags`
- 이미지: `_attach_stock_images`(AI·쇼핑, 제미나이 웹 → API/스톡) / `_fill_celeb_captures`(연예, 방송 캡처)

**③ 업로드**(`naver.save_draft`) → Playwright로 스마트에디터 조작

**오케스트레이터** `run_ai_daily.py`가 ①②③을 돌린다. 편 사이 `--stagger`초 대기.

### ★연예편 이미지 자동첨부는 껐다 (2026-08-08 에디님 지시)
`gen_celeb_ai.CELEB_AUTO_PHOTOS = False`. 캡처도 썸네일도 **만들지 않고**, 본문의
`[사진N - 장면 / 출처: 프로그램(방송사)]` 마커만 남긴다(`pipeline._fill_celeb_captures`는 캡처 파일이
없으면 마커를 보존). 이유 — 자동 캡처가 엉뚱한 화면을 붙여서 **지우고 다시 넣는 게 더 힘들었다**:
- 이호선이 출연한 **옛 JTBC 토크쇼(성재기 회차)** 캡처가 이혼숙려캠프 글 대표사진으로 들어감
- **'31기 막방 LIVE' 예고 그래픽**, **다른 기수·다른 출연자**(솔로 리액션 광수)가 28기 옥순 글에 들어감

다시 켜려면 프레임이 ①지정 프로그램 화면인지 ②예고 그래픽이 아닌지 ③기수가 맞는지를 비전으로
판정하는 `_scene_ok`를 먼저 붙일 것. `_face_ok`는 **이름만** 보고 프로그램을 안 본다.
마커 품질 규칙은 `BODY_PROMPT_AI10`에 있다(`출처: 방송`·`SNS`·채널명 없는 `유튜브` 금지).

**★사진 출처는 '찾을 수 있게' 세 칸으로 쓴다 (2026-08-10 에디님 지시)**
`출처: 이혼숙려캠프(JTBC)`만 있으면 **몇 회차의 어느 장면인지 몰라 유튜브에서 찾을 수 없다**는 지적.
```
[사진3 - 상담 테이블에서 부부를 마주 본 이호선의 정색한 표정
 / 출처: JTBC '이혼숙려캠프' 94회(2026-08-06)
 / 유튜브 검색: 이혼숙려캠프 코인부부 이호선 상담 테이블]
```
- 회차·방송일·검색어는 `PICK_PROMPT_PURE`가 기사에서 뽑는다(`회차`·`방송일`·`장면검색어`).
  기사에 없으면 정규식으로 `\d+회|\d+기`를 찾고, 그래도 없으면 **빈칸으로 둔다(지어내기 금지)**.
- LLM이 형식을 빠뜨려도 **`_enrich_photo_sources()`가 코드로 보정**한다 — 회차·방송일을 끼우고,
  장면 설명에서 특징어 1~2개(조사 제거)를 뽑아 **사진마다 다른 검색어**를 붙인다.
  `출처: 직접 촬영(해당 툴 화면)`(AI 화면)은 자동첨부 대상이라 건드리지 않는다.

**★맨 끝 `@출처` 줄에도 프로그램명을 넣는다 (2026-08-11 에디님 지시)**
`@출처 : MBC`만 있으면 오은영처럼 여러 프로그램에 나오는 인물은 어느 방송을 인용했는지 알 수 없다.
→ `_source_label(media, program)`이 **`MBC '오은영 리포트-결혼 지옥'`** 형태로 만든다
(프로그램에 이미 `(MBC)`가 붙어 있으면 중복 제거). 정보형(`gen_drama_info`)도 같은 줄을 붙인다.

⚠️**'출처'를 본문 전체에서 찾으면 안 된다**(같은 날 실측 버그). 사진 마커가
`[사진1 - … / 출처: MBC '오은영 리포트' 180회]`라서 전체 검색으로는 ①"이미 출처가 있다"고 오판해
끝 줄을 안 붙이고 ②보강 치환이 **사진 마커를 덮어쓴다**. `_ensure_source_line`은 **줄 시작이
`@출처`/`출처`인 줄만** 본다.

**★사진 마커는 연달아 붙이지 않는다 (2026-08-11 에디님 지적)**
실측: 핑퐁 편에서 마커 7개가 2·2·3개씩 뭉쳐 나왔다(`[사진5][사진6][사진7]` 연속).
그러면 사진을 한 자리에 몰아 넣게 되고 글이 '사진 덩어리 + 글 덩어리'로 갈린다
— 체험단 블로그의 IMG IMG 문제와 같다. 프롬프트 금지 + **`_spread_photo_markers()` 코드 강제**.
- 이미 잘 흩어져 있으면 **건드리지 않는다**(원래 배치가 문맥상 자연스럽다). 뭉친 글만 교정.
- ⚠️처음엔 '연속 마커를 뒤쪽 빈자리로 한 칸씩 밀기'로 만들었는데 **뒤에 본문이 없으면 갈 곳이 없어
  그대로 쌓였다**(40회 돌고도 3개 뭉침 잔존). → 마커를 전부 뽑아 **본문 문단 사이에 균등 배치**하고,
  문단 수보다 마커가 많으면 남는 건 버린다(앞뒤에 글이 없는 사진 자리는 쓸모가 없다).
- `@출처`·해시태그 줄 뒤로는 보내지 않는다. 배치 후 `[사진N]` 번호를 다시 매긴다.
- 검증: 최근 원고 9편에 적용 → 뭉친 1편만 재배치, 정상 8편은 그대로, 전부 뭉침 0.

- 사진은 이슈형과 동일하게 **자동첨부 없음** + `_enrich_photo_sources`로 출처 3칸 보정.

`10:28 / 12:46 / 12:47 / 12:50 / 14:24 / 14:30 / 16:15 / 16:59 / 20:59 / 22:08` —
**10~22시, 중심 12~16시, 새벽 0건**이었다. 홈피드는 발행 직후 노출 기회가 가장 커서
보는 사람이 없는 새벽에 내보내면 초기 클릭·체류가 안 붙고 이후 노출까지 불리해진다.
→ **생성·업로드는 새벽(01:30~05:40), 발행은 낮.** 새벽에 발행하지 말 것.
슬롯을 매일 지터로 흔드는 이유: 매일 같은 시각이면 그 자체가 기계 티다.

- 예약 간격을 랜덤으로 두는 이유: 규칙적이면 AI 대량 발행으로 보인다.
- **예약 설정 실패 시 즉시 발행을 막고 임시저장으로 전환한다**(`_set_reserve_time` 실패 시). 그대로 확정을 누르면 전부 즉시 공개돼 사고가 난다.
- 자동 발행이므로 **`[[경험 보태기: …]]` 같은 편집용 슬롯은 업로드 직전 자동 제거**된다(프롬프트 금지 + `process_post` 이중 방어).

## 글쓰기 규칙

- **존댓말.** 반말 종결 금지.
- **도입부 인사·자기소개 금지.** LLM이 없는 필명("엘라", "햄찡이")을 지어낸 사고가 반복돼 프롬프트 금지 + `pipeline._strip_greeting_intro` 이중 방어.
- **유튜브 채널 홍보·`@출처` 문단 제거**(연예편은 방송 출처만 유지). `_strip_youtube_cta`.
- **제목은 '반전형'** — 통념을 깔고 뒤집되 **결론은 감춘다**. 실측으로 조회수가 나온 구조를 `gen_ai.TITLE_PROMPT`에 예시로 박아뒀다. 결론을 제목에 다 말하는 정보 요약형은 조회수가 안 나온다.
- **'AI가 쓴 티' 제거**(3개 생성기 모두): 짧게 툭툭 끊기, 구체적 숫자·장면, 곁가지 남기기. 금지 — `또한/따라서/이처럼/결론적으로/정리하자면`, `~해보시기 바랍니다`, `정말 유용한/놀라운`, 문단마다 같은 리듬, 항목 3개씩 균일 나열.
- **지어낸 수치·가짜 할인·미검증 후기 금지.**

## 중복 방지 (`history.py`, 2026-08-10 신설)

에디님 지적 "이전에 했던 내용이 계속 중복된다"의 정체를 실측했더니 **주제가 아니라 '제목 틀'과 '인물'**이었다.
- `AI한테 ~시켰더니/물었더니` 형식이 최근 40편 중 **9편(22%)**. 8/6은 3편 전부, 8/5도 3편이 같은 틀.
- 연예는 인물이 돌고 돈다 — 옥순×3, 나는솔로×3, 광수×2. 상투어 `결국`×5, `술렁/발칵`×4.

원인 세 가지: ①주제 중복검사가 `ai_topics_used.json`의 **정확 문자열 비교**뿐 ②연예 `exclude_persons`가
**한 번 실행 안**에서만 유효 ③생성기가 '이미 발행한 제목'을 아예 모른 채 제목을 지음.

**해결** — `history.py`가 **블로그에 실제 발행된 제목**을 읽어(공개 API, 세션 불필요) 판단한다.
- `recent_titles(60)` / `recent_posts()` — 인메모리+파일 캐시(`work/recent_titles.json`)
- `too_similar(cand, titles, 0.5)` — 토큰 겹침. **조사를 떼고 비교**(`정부지원금이`≠`정부지원금,` 때문에
  재탕을 놓쳤다) + 4자 이상 핵심어는 제목에 박혀 있으면 겹친 것으로 본다.
- `banned_patterns()` — 최근 2회 이상 쓴 틀을 금지 목록으로. `prompt_block()`이 프롬프트에 그대로 들어간다.
- `recent_celeb_names()` / `mark_celeb_used()` — 연예 인물·프로그램을 **10일간** 기록해 제외
  (`work/celeb_used.json`). ★기록은 `CELEB_AUTO_PHOTOS=False` 조기반환 경로에도 들어가 있어야 한다.

물린 곳: `gen_ai.derive_topics`(주제 필터+프롬프트) · `gen_ai` 제목 후보 필터 ·
`gen_celeb_ai.pick_article`(인물 제외) · 연예 제목 프롬프트 · `gen_shopping` 제목 재생성.
검증: 재탕 4건(정부지원금·사진정리·제습기·AI부업) 전부 차단, 새 주제 4건 전부 통과.

## 검증된 함정 (재발 감시)

- 🔴**인용구 변환이 문장을 쪼개면 안 된다**(2026-08-11 에디님 지적, 발행분에서 발견).
  `quote_select.apply_quotes`가 **뒤쪽만** 봐서(`after_raw`에 한글이 이어지는지) 판단했다.
  그래서 인용할 부분이 **문장 끝에 붙어 있으면** 뒤가 비어 '조각 아님'으로 오판하고 앞을 잘라냈다:
  «이럴 줄 알았다면 결혼 안 했다.» → 본문 `이럴 줄` + 인용구 `알았다면 결혼 안 했다.` (말이 안 된다)
  → **항상 `_sentence_span`으로 문장 경계를 찾아 그 문장 전체를 인용**한다. 남는 앞/뒤가
  문장부호 없이 20자 이하인 조각이면 인용구에 붙여 살린다. `_SENT_END`는 `.!?…`+닫는 부호까지 본다
  (마침표만 보면 물음표·말줄임표로 끝나는 구어체 문장을 놓친다).
  ※`_apply_step_quotes`·`_apply_orphan_subheads`는 줄 단위 제자리 변환이라 이 문제가 없다.

- **네이버 세션**: `is_logged_in()`은 파일 존재만 본다. 무인 실행은 **`session_alive()`**로 확인. ★이 함수는 **로그인이 반드시 필요한 페이지**(`GoBlogWrite.naver`)를 봐야 한다 — 예전엔 비로그인도 열리는 `BlogHome`을 봐서 만료된 세션에도 True가 나왔고 0/5 전멸했다.
- **"본문 영역을 찾지 못했습니다"** = 셀렉터가 아니라 **로그인 실패**를 먼저 의심하라.
- **★네이버 IP 보안이 켜져 있으면 세션이 하루도 못 간다.** 로그인 화면에서 `IP 보안`을 OFF로 두면 몇 주 유지된다. 반복 재로그인의 진짜 원인이었다.
- **브라우저는 `naver.open_browser()`** — **Playwright 내장 + 저장 쿠키가 기본이자 정답**. 실제 Chrome 프로필·CDP 경로는 프로필 잠금("프로필을 여는 동안 문제가 발생했습니다")과 로그인 소실을 반복해 기본에서 뺐다.
- **크롬을 `pkill`(SIGKILL)로 죽이지 말 것.** 프로필이 깨져 로그인이 날아가고 이미지 생성이 통째로 실패한다. `kill -TERM` → 대기 → `Singleton*` 락 정리 순서로.
- **실행 중 프로세스는 옛 코드를 물고 있다.** 파이썬은 실행 중 파일 변경을 반영하지 않으므로, 코드를 고쳤으면 **돌던 작업을 멈추고 새로 시작**해야 한다.
- **중복 실행 금지**: `run_ai_daily._acquire_lock()`. 맥이 자다 깨며 어제 작업과 오늘 배치가 동시에 브라우저를 띄워 전멸한 적 있다.
- **스크래핑은 `domcontentloaded`** — 네이버에서 `networkidle`은 안 끝나 타임아웃으로 죽는다.
- **제로폭 공백(U+200B)**: LLM이 넣으면 `strip()`에 안 지워져 '소제목'으로 오인 → 빈 인용박스가 대량 생성. `process_post`가 제거한다.
- **마커가 문장에 붙어 있으면 파서가 못 잡는다**(`…씁니다. [사진7 - …]`). 파서는 줄 전체 매칭이라 본문에 대괄호가 노출됐다 → `process_post`가 마커를 독립 줄로 분리한다.
- **제목 노이즈**: `★`, `**마크다운**`, 설명문("…5개 뽑았습니다")이 제목으로 나온다. `gen_ai._clean_title`이 거른다.
- **소재뱅크 소진 시 이력을 초기화하지 말 것.** 예전엔 초기화해서 같은 주제가 며칠 간격으로 재등장했다. 지금은 트렌드에서 새로 뽑는다.
- **나는솔로 가명**(옥순·영숙·영수)은 기수마다 반복돼 얼굴로 신원 판별이 불가능하다. 검색어에 **프로그램+기수**를 넣고(`fetch_multi(context=…)`) 자막의 이름·기수로 검증. 확보량이 적으면 자리표시자로 두는 게 낫다(틀린 인물 삽입 방지).

## 외부 의존

- **`claude -p`**(구독 요금제)로 텍스트 생성. 최초 1회 `claude login`. 임베드 세션에서 "Not logged in"이 나면 일반 터미널에서 실행. 헬퍼 `claude_cli.run_claude_p`.
- **Playwright + Chromium**: `python3 -m playwright install chromium`.
- **Gemini API 키**(`image_finder._load_key("GEMINI_API_KEY")`): 썸네일·비전 검증(얼굴/기수 판정)·이미지 폴백.
- **이미지 = 제미나이 웹 전용**(`web_image.py`). 프로필 `session/gemini_profile`. **창 하나로 한 편 분량을 몰아서 생성**하고, 실패분은 같은 창에서 재시도한다. ★**ChatGPT는 자동 경로에서 완전히 제거**했다(이미지 생성 한도가 자주 걸려 실패만 키움). 제미나이도 실패하면 `pipeline`이 Gemini API/스톡으로 채운다.
  - 제미나이 함정: `fetch(blob:)`은 CORS로 막혀 **엘리먼트 스크린샷**이 실질 경로 → 겹친 UI를 `_trim_ui()`로 크롭. 새 이미지 판정은 src가 아니라 **개수 증가**로 본다(blob URL을 재사용해 새 이미지를 "이미 본 것"으로 오판했다).
- **조회수**는 글 목록 API가 빈 값을 주므로 **관리자 통계 API**(`blog_report.fetch_stats`)에서 가져온다. `admin.blog.naver.com` 쿠키가 필요하고 `login_and_save`가 로그인 직후 통계 페이지를 방문해 확보한다.

## 네이버 에디터 셀렉터

`naver.py` 상단 `SEL_*`는 후보 리스트다. 네이버가 클래스명을 자주 바꾸므로 실패 시 후보를 추가한다. 본문은 `mainFrame` iframe 안에 있고, 못 찾으면 최상위 문서로 폴백한다.
